2 KYC身份验证

提交个人信息进行KYC验证（信息仅发送给KYC服务，不存储在我们的服务器）

📋 KYC信息验证
3 获取Nonce

从后端获取一次性nonce进行签名

4 签名验证

签名消息并提交验证请求（包含KYC ID）

5 检查状态

验证成功后，检查你的验证状态

📋 系统说明

  1. 隐私保护设计：系统不存储您的原始KYC信息，只存储验证状态和KYC ID
  2. KYC验证流程：KYC信息发送给模拟的KYC服务进行验证，返回KYC ID
  3. 钱包签名：使用私钥签名证明您拥有该钱包地址
  4. JWT令牌：验证成功后生成JWT令牌，包含KYC ID但不包含原始KYC信息
  5. 人类验证上链：使用VeriChain合约进行人类验证上链，防止女巫攻击

环境要求：

  1. Hardhat本地网络正在运行（npm run node）
  2. VeriChain合约已部署（npm run deploy）
  3. 后端服务正在运行（npm start）
  4. MetaMask连接到Hardhat网络（链ID: 31337, RPC: http://localhost:8545）

网络切换帮助：

  1. 点击"快速切换到Hardhat网络"按钮自动配置
  2. 或手动在MetaMask中添加网络：名称: "Hardhat Local", RPC: "http://localhost:8545", 链ID: "31337"
